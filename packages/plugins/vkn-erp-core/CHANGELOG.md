# Vietkeynet ERP Core Plugin

Core business logic and system configuration for the comprehensive Vietkeynet ERP system.

## Features

- Multi-tenant architecture
- RBAC with 16+ roles and 560+ permissions
- Company settings and configuration
- Audit logging
- System settings
- Multi-currency support
- Localization (Vietnamese, English, Chinese)
